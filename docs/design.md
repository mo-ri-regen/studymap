# StudyMap 画面設計

最終更新: 2026-11-01

スマホで使うことを優先する。パソコンでは、スマホの幅の画面を中央に置く。

## 色と雰囲気

- テーマ: 前向きな緑（成長・達成。「地図」の名前にも合う）
- 色の役目

| 役目           | 色             |
| -------------- | -------------- |
| メインの色     | 緑 `#1D9E75`   |
| 緑の濃い文字   | `#0F6E56`      |
| 緑の薄い背景   | `#E1F5EE`      |
| 遅れ・注意     | 黄色系         |
| エラー・削除   | 赤系           |
| 最初の計画の線 | 灰色 `#888780` |

- スマホのダークモード（黒い背景）にも対応する
- 飾りは少なく、平らな見た目にする（グラデーションや影は使わない）

## 共通

- 画面の下にタブを置き、「ホーム」「記録」「設定」を切り替える
- 計画がないとき（初めて開いたとき）は、タブを出さずに「初めて開いたとき」の画面を出す
- 確認が必要な操作（新しい計画・読み込み・すべて消す）は、アプリの中の確認画面（文と「やめる」・実行のボタン）で確かめる

## 画面ごとの配置

### 初めて開いたとき

- アプリ名と、1行の説明（1日に何問解けばいいか、いつ受験できるかを計算します）
- 「計画を作る」ボタン（メイン）
- 「サンプルで試す」ボタン（ポートフォリオを見る人がすぐ中身を見られるように）
- データがこの端末のブラウザに保存されることを小さく書く

### 計画の作成（3ステップ）

画面の上に、いまどのステップかを示す線を出す。ステップ1には「やめる」を置き、押すと保存せずに前の画面に戻る。

最初に入っている値: 開始日は今日、周回数は1、勉強する曜日は月〜日の全部、計算のしかたは「試験日から」。資格名・教材名・総問題数・試験日は空にする。

**ステップ1: 教材**

- 資格名: プルダウンから選ぶ。一覧にないときは「その他（自分で入力）」を選ぶと入力欄が出る（一覧は下の「資格の一覧」）
- 教材名・総問題数・周回数
- 「合計 ○問 を解きます」と、掛け算の結果をその場で出す

**ステップ2: 日程**

- 計算のしかた: 「試験日から」（モードA）と「ペースから」（モードB）の切り替え
  - 「ペースから」では、試験日の欄が「1日に解ける問題数」に変わる
- 開始日、試験日（または1日に解ける問題数）、勉強する曜日
- 「くわしい設定」は最初は閉じておく: 予備日（初期値0日）、1日の上限（初期値50問）
- 入力の間違いは、入力欄の枠を赤くして、すぐ下に理由を出す
  - 出すのは、その欄を離れたときと「次へ」を押したとき。一度出たら、直した時点で消える
  - 間違いがあるうちは、次のステップに進めない

**ステップ3: 計算結果**

- 1日の目標（モードB では勉強が終わる日と受験おすすめ日）、勉強する日数、終わる日を大きく出す
  - 1日の目標は、日によって1問ずれるときは多いほうを出す（例: 100問を3日なら「1日 34問」）
- 上限を超えたときだけ、黄色で「この日程は厳しい」と出す
- 日ごとの計画は、最初は3日分だけ見せ、「すべて見る」で全部を開く
  - 1行に、日付・その日の目標・それまでの合計を出す（例: 「11/2（月） 34問 合計 34 / 1200問」）。上限を超えた日は黄色
- 「戻る」と「この計画で始める」（保存してトップ画面へ）

### トップ（ホーム）

上から順に:

1. 資格名・教材名・試験日（あと何日か）
   - 「ペースから」で作った計画は、試験日の代わりに受験おすすめ日（「○以降・あと○日」）
   - 当日は「今日」（受験おすすめ日は、当日から「受験できます」）。試験日を過ぎたら「あと何日」は出さない
2. 今日の目標（いちばん大きく）、解いた数の進み具合の棒、「+1」「+5」「+10」ボタン
   - 今日が勉強する曜日でないときは、そのまま「0問」と出す
   - 開始日がまだ先のときは、今日の目標の代わりに「○から始まります・あと○日」と出す。ボタンは使え、解いた分は進んだ分になる
3. 達成率と予定との差（遅れは黄色で「○問遅れ」、進んでいれば「○問前倒し」）
   - 達成率は小数を切り捨てて、問題数も出す（例: 「35%（420 / 1,200問）」）。100%は全部解いたときだけ
   - 遅れも前倒しもないときは、差は何も出さない
4. 進捗グラフ（灰: 最初の計画、緑: 実績、緑の点線: これからの計画）
   - 累計の折れ線。横は日付、縦はその日までに解いた合計（0〜総問題数×周回数）
   - 横の範囲は開始日から、「計画の最後の日」と「最後に記録した日」の遅いほうまで
5. 終わる見込みの日（進んでいれば「予定より○日早く終わりそう」）
   - 計画の最後の日を過ぎても残っているときは、黄色で「計画の最後の日を過ぎました。残り ○問」

### 記録

上から順に:

1. 日付（左右の矢印で前後の日に移る。今日より後には進めない。開始日より前には戻れない）
2. その日に解いた数と目標、「−1」「+1」「+5」「+10」ボタン
   - 目標は、今日はトップと同じ「今日の目標」、過去の日は最初の計画のその日の目標
3. 合計を数字で直す欄（「保存」を押したときに保存する。間違った数は赤い枠と理由を出して保存しない）
4. これまでの記録（日ごとに「解いた数 / 目標」。0問の日は黄色。まだ終わっていない今日は黄色にしない）
   - 開始日から今日までの勉強する日すべてと、勉強する日以外で解いた日を、新しい日を上にして並べる
   - 行を押すと、その日に移って直せる

### 設定

1. 今の計画: 資格・教材・試験日。「計画を変える」から日程や設定を直す（最初の計画を作り直し、記録は残す）
   - 「計画を変える」は作成画面と同じ3ステップを、今の計画が入った状態で出す。どの項目も直せる。最後のボタンは「この計画に変える」
2. データ: ファイルに書き出す、ファイルから読み込む
   - 読み込むファイルの中身が正しければ「今の計画と記録は、読み込んだファイルの中身に置き換わります」と確認し、OKなら置き換えてトップへ。中身がおかしければ理由を出す
3. やり直す
   - 新しい計画を作る: 押したときに「今の計画と記録は消えます。先にファイルに書き出しておくと安心です」と確認を出す
     - OKなら作成画面へ移る。今の計画と記録は、新しい計画を「この計画で始める」で保存したときに消す（途中でやめれば残る）
   - すべてのデータを消す: 赤い文字。押したときに「計画と記録をすべて消します。元には戻せません。先にファイルに書き出しておくと安心です」と確認を出す。消したあとは初めて開いたときの画面

### 完了

全部解き終わったとき、または試験日を過ぎたときに出す。

- 「試験日から」の計画: 全部解いたとき、または試験日の次の日から
- 「ペースから」の計画: 全部解いたときだけ（受験おすすめ日は「この日以降」なので、過ぎても完了にしない）
- ホームの代わりに出し、下のタブは残す。記録を直して全部解いていない状態に戻れば、トップに戻る

1. 「おつかれさまでした」と資格名
2. 振り返りの数字: 解いた問題、勉強した日、いちばん多く解いた日の数、予定との差
   - 解いた問題 = 記録の合計。勉強した日 = 1問以上解いた日の数（勉強する曜日以外も含む）
   - いちばん多く解いた日 = その数と日付（例: 「45問（11/20）」）
   - 予定との差: 全部解いたときは、最後に解いた日と最初の計画の終わる日を比べて「予定より○日早く終わりました」「予定どおり終わりました」「予定より○日遅く終わりました」。試験日を過ぎて残ったときは「残り ○問」
3. 進捗グラフ（最初から最後まで）
4. 「新しい計画を作る」（メイン）、「記録を書き出す」

### 保存がうまくいかないとき

- 保存されたデータが壊れているとき: 「保存されたデータを読み込めませんでした」と出し、データは消さない。その下に「ファイルから読み込む」と「すべてのデータを消す」を置く（確認は設定画面と同じ）
- ブラウザの設定などで保存できないとき: 「このブラウザでは保存できません。プライベートモードなどをやめてください」と出す

## 資格の一覧

いったん AWS 認定資格だけにする（2026-10-31 時点で受けられるもの）。名前のうしろの【】は、試験コードの頭の3文字の略称。

**基礎（Foundational）**

- AWS Certified Cloud Practitioner【CLF】
- AWS Certified AI Practitioner【AIF】

**アソシエイト（Associate）**

- AWS Certified Solutions Architect - Associate【SAA】
- AWS Certified Developer - Associate【DVA】
- AWS Certified CloudOps Engineer - Associate【SOA】
- AWS Certified Data Engineer - Associate【DEA】
- AWS Certified Machine Learning Engineer - Associate【MLA】

**プロフェッショナル（Professional）**

- AWS Certified Solutions Architect - Professional【SAP】
- AWS Certified DevOps Engineer - Professional【DOP】
- AWS Certified Generative AI Developer - Professional【AIP】

**専門知識（Specialty）**

- AWS Certified Security - Specialty【SCS】

補足:

- 一覧の最後に「その他（自分で入力）」を置く
- 入れなかったもの: Advanced Networking - Specialty（2026-12-31 で終了）、AI Business Strategist（ベータ版）
- CloudOps Engineer は、以前の SysOps Administrator の試験コード（SOA-C03）を引き継いでいるので【SOA】
- 資格名は略称を含めた形のまま保存・表示する
- 一覧は1つのファイルにまとめ、変わったときに直しやすくする
