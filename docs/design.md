# StudyMap 画面設計

最終更新: 2026-10-31

スマホで使うことを優先する。パソコンでは、スマホの幅の画面を中央に置く。

## 色と雰囲気

- テーマ: 前向きな緑（成長・達成。「地図」の名前にも合う）
- 色の役目

| 役目           | 色             |
| -------------- | -------------- |
| メインの色     | 緑 `#1D9E75`   |
| 緑の濃い文字   | `#0F6E56`      |
| 緑の薄い背景   | `#E1F5EE`      |
| 遅れ・注意     | 黄色系         |
| エラー・削除   | 赤系           |
| 最初の計画の線 | 灰色 `#888780` |

- スマホのダークモード（黒い背景）にも対応する
- 飾りは少なく、平らな見た目にする（グラデーションや影は使わない）

## 共通

- 画面の下にタブを置き、「ホーム」「記録」「設定」を切り替える
- 計画がないとき（初めて開いたとき）は、タブを出さずに「初めて開いたとき」の画面を出す

## 画面ごとの配置

### 初めて開いたとき

- アプリ名と、1行の説明（1日に何問解けばいいか、いつ受験できるかを計算します）
- 「計画を作る」ボタン（メイン）
- 「サンプルで試す」ボタン（ポートフォリオを見る人がすぐ中身を見られるように）
- データがこの端末のブラウザに保存されることを小さく書く

### 計画の作成（3ステップ）

画面の上に、いまどのステップかを示す線を出す。

**ステップ1: 教材**

- 資格名: プルダウンから選ぶ。一覧にないときは「その他（自分で入力）」を選ぶと入力欄が出る（一覧は下の「資格の一覧」）
- 教材名・総問題数・周回数
- 「合計 ○問 を解きます」と、掛け算の結果をその場で出す

**ステップ2: 日程**

- 計算のしかた: 「試験日から」（モードA）と「ペースから」（モードB）の切り替え
  - 「ペースから」では、試験日の欄が「1日に解ける問題数」に変わる
- 開始日、試験日（または1日に解ける問題数）、勉強する曜日
- 「くわしい設定」は最初は閉じておく: 休みの日、予備日（初期値0日）、1日の上限（初期値50問）
- 入力の間違いは、入力欄の枠を赤くして、すぐ下に理由を出す

**ステップ3: 計算結果**

- 1日の目標（モードB では勉強が終わる日と受験おすすめ日）、勉強する日数、終わる日を大きく出す
- 上限を超えたときだけ、黄色で「この日程は厳しい」と出す
- 日ごとの計画は、最初は3日分だけ見せ、「すべて見る」で全部を開く
- 「戻る」と「この計画で始める」（保存してトップ画面へ）

### トップ（ホーム）

上から順に:

1. 資格名・教材名・試験日（あと何日か）
2. 今日の目標（いちばん大きく）、解いた数の進み具合の棒、「+1」「+5」「+10」ボタン
3. 達成率と予定との差（遅れは黄色で「○問遅れ」、進んでいれば「○問前倒し」）
4. 進捗グラフ（灰: 最初の計画、緑: 実績、緑の点線: これからの計画）
5. 終わる見込みの日（進んでいれば「予定より○日早く終わりそう」）

### 記録

上から順に:

1. 日付（左右の矢印で前後の日に移る。今日より後には進めない）
2. その日に解いた数と目標、「−1」「+1」「+5」「+10」ボタン
3. 合計を数字で直す欄
4. これまでの記録（日ごとに「解いた数 / 目標」。0問の日は黄色）

### 設定

1. 今の計画: 資格・教材・試験日。「計画を変える」から日程や設定を直す（最初の計画を作り直し、記録は残す）
2. データ: ファイルに書き出す、ファイルから読み込む
3. やり直す
   - 新しい計画を作る: 押したときに「今の計画と記録は消えます。先にファイルに書き出しておくと安心です」と確認を出す
   - すべてのデータを消す: 赤い文字。押したときに確認を出す

### 完了

全部解き終わったとき、または試験日を過ぎたときに出す。

1. 「おつかれさまでした」と資格名
2. 振り返りの数字: 解いた問題、勉強した日、いちばん多く解いた日の数、予定との差
3. 進捗グラフ（最初から最後まで）
4. 「新しい計画を作る」（メイン）、「記録を書き出す」

## 資格の一覧

いったん AWS 認定資格だけにする（2026-10-31 時点で受けられるもの）。名前のうしろの【】は、試験コードの頭の3文字の略称。

**基礎（Foundational）**

- AWS Certified Cloud Practitioner【CLF】
- AWS Certified AI Practitioner【AIF】

**アソシエイト（Associate）**

- AWS Certified Solutions Architect - Associate【SAA】
- AWS Certified Developer - Associate【DVA】
- AWS Certified CloudOps Engineer - Associate【SOA】
- AWS Certified Data Engineer - Associate【DEA】
- AWS Certified Machine Learning Engineer - Associate【MLA】

**プロフェッショナル（Professional）**

- AWS Certified Solutions Architect - Professional【SAP】
- AWS Certified DevOps Engineer - Professional【DOP】
- AWS Certified Generative AI Developer - Professional【AIP】

**専門知識（Specialty）**

- AWS Certified Security - Specialty【SCS】

補足:

- 一覧の最後に「その他（自分で入力）」を置く
- 入れなかったもの: Advanced Networking - Specialty（2026-12-31 で終了）、AI Business Strategist（ベータ版）
- CloudOps Engineer は、以前の SysOps Administrator の試験コード（SOA-C03）を引き継いでいるので【SOA】
- 資格名は略称を含めた形のまま保存・表示する
- 一覧は1つのファイルにまとめ、変わったときに直しやすくする
